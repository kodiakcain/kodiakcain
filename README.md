## Featured Project - OrbitOps

**OrbitOps** is an open-source Python command-line toolkit I'm developing for satellite tracking and orbital analysis using publicly available CelesTrak data.

It uses **OMM orbital data and SGP4 propagation** to calculate and visualize spacecraft motion.

Current capabilities include:

- Satellite latitude, longitude, and altitude calculation
- TEME Cartesian position and velocity
- Satellite catalog search and information
- 3D distance calculations between spacecraft
- Continuous spacecraft position tracking
- Predicted ground-track generation
- Ground-track CSV export
- Interactive 3D orbital visualization
- Local orbital-data caching
- Rich-powered command-line interfaces
- Automated testing, linting, and static type checking

OrbitOps is packaged and distributed through **PyPI** and is under active development with additional orbital-analysis and visualization capabilities planned.
